Arquitetura do Servidor MCP da YouShop Model Context Protocol Specification

O Model Context Protocol (MCP) padroniza a troca de informações entre os LLMs da YouShop e os microsserviços internos. Ele impede alucinações forçando contratos tipados de entrada/saída via JSON-RPC.

📦 1. Ferramenta: check_content_delivery

Valida o status da entrega do infoproduto nas áreas de membros integradas, checando webhooks e status HTTP de entrega.

{ "name": "check_content_delivery", "description": "Verifica se as credenciais de acesso foram despachadas para o comprador", "inputSchema": { "type": "object", "properties": { "transaction_id": { "type": "string" }, "buyer_email": { "type": "string" } }, "required": ["transaction_id", "buyer_email"] } }

🔗 2. Ferramenta: verify_affiliate_attribution

Cruza o histórico de cliques, cookies de sessão e a atribuição de split de pagamento da YouShop para auditar comissões.

{ "name": "verify_affiliate_attribution", "description": "Audita o caminho de atribuição do creator e valida a regra de comissionamento", "inputSchema": { "type": "object", "properties": { "creator_id": { "type": "string" }, "transaction_id": { "type": "string" } }, "required": ["creator_id", "transaction_id"] } }

🛡️ 3. Ferramenta: get_transaction_audit

Audita os logs transacionais no gateway de pagamento (adquirente, status de liquidação, risco de antifraude e histórico de chargeback).

{ "name": "get_transaction_audit", "description": "Retorna o dossiê transacional completo sem expor dados sensíveis de cartão", "inputSchema": { "type": "object", "properties": { "transaction_id": { "type": "string" }, "include_risk_score": { "type": "boolean" } }, "required": ["transaction_id"] } }
